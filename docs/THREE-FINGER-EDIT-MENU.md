# 三指下滑编辑菜单

日期：2026-09-29

## 范围与实现

基于 `main` 的 `f3e6d75`（v1.3.6），分支 `feat/three-finger-edit-menu`

- 设置 → 手势新增三指下滑开关，默认开启，写入已有 `paint_prefs`
- 三个固定 pointer ID 在 650ms 内共同下滑至少 48dp，才识别为菜单手势；允许少量横向偏移，并检查三个手指位移的一致性
- 全部手指抬起后显示菜单；候选期间消费触摸直到最后抬手，避免下滑后重做、画布位移和尾指落笔
- 轻点保留三指重做；未移动时仍在 420ms 后连续重做，每 110ms 一次；移动超过 8dp 后停止等待中的连续重做
- 已开始的双指导航不被抢占；滤镜预览、活动液化、变换、裁切和透光台对位沿用原有手势
- 第四根手指、手写笔混入、取消事件使本次候选失效；关闭开关恢复原多指导航路径

## 编辑语义

已有 `copyOrCutSelection` 是复制/剪切到变换或新图层，没有通用像素剪贴板，因此没有将其重命名为粘贴

新增剪贴板完全由 C++ 持有，Kotlin 只镜像可用操作标志，不在 UI 层持有像素副本

- 只复制当前普通像素图层，存在选区时按选区遮罩复制，否则复制画布范围内的像素
- 剪切使用原生撤销事务；拒绝背景、锁定、Alpha 锁定及父组锁定的图层
- 空内容复制失败时保留原剪贴板
- 粘贴保留原始画布位置，创建根级普通像素图层，可重复粘贴，可撤销；不重复套用选区遮罩
- 剪贴板只在当前画作会话内有效，新建、打开、关闭画作时释放；不接入系统剪贴板，不支持跨画作粘贴
- 新增零载荷录制操作 43/44/45，当前回放器重放复制、剪切、粘贴；旧版本回放器会跳过这些操作，不能完整还原包含这些操作的录像，但不会因新增载荷错位

## 影响范围与检查

手势：双指撤销、三指重做/连续重做、视口导航、笔模式、触控取消与离页清理

文档：当前图层、选区羽化、锁定保护、剪切/粘贴撤销、图层与缩略图刷新、录制回放、文档释放

不修改既有 JNI 签名，新增 `canvasClipboardCapabilities`、`copyCanvasToClipboard`、`pasteCanvasClipboard`，全部走 `runCore` 串行线程

## 2026-10-04：可自定义菜单

基于主线 `1fce2a44`（1.4.2），在独立分支增加菜单内容配置：

- 初始顺序仍为剪切、复制、粘贴；可添加现有快捷操作中的 18 项操作
- 在三指菜单底部或「设置 → 手势设置 → 自定义三指菜单」进入编辑
- 点击可添加操作将其放到末尾；用上下箭头排序，用减号移除，至少保留一项
- 编辑为草稿，保存才生效；取消、返回或点击对话框外不保存；恢复默认也需保存确认
- 独立存储在 `paint_prefs.canvas_edit_menu_actions`，不修改快捷操作浮窗的配置
- 读取时忽略未知项、去重并保留顺序；配置缺失、为空或全部失效时恢复原有三项
- 菜单最多每行三项，窄屏和大字体会自动减少列数，内容超高时滚动；底部按钮空间不足时换行
- 剪贴板操作沿用原能力检查、录制与撤销逻辑，其他操作调用已有的快捷操作分发；仅含快捷操作时隐藏剪贴板提示

影响范围为菜单展示、设置入口和配置保存；未更改手势识别、C++ 或 JNI 接口。回归应覆盖设置主页与绘画页两个入口、独立快捷操作浮窗、剪贴板能力状态及三指轻点重做。

### 手动验收

1. 新安装打开画布，三指下滑，确认初始菜单依次为剪切、复制、粘贴
2. 进入自定义，添加「画笔/橡皮」，上移到第一项，保存后再次下滑，点击它检查工具切换
3. 再次编辑，移除任意项后取消，确认菜单不变；恢复默认后取消也应保持原菜单
4. 保存自定义顺序，结束并重启应用，确认顺序保留；快捷操作浮窗仍保留它自己的配置
5. 移除到仅剩一项，确认最后一项不能移除；添加较多操作后检查列表滚动及保存、关闭按钮
6. 在设置的手势页打开同一个编辑器，保存后回到画布检查菜单更新；关闭三指菜单手势时仍可编辑配置
7. 在普通绘画图层画几笔，复制、粘贴，确认产生新图层；空图层和无剪贴板内容时对应操作应禁用
8. 复查三指轻点重做、二指移动缩放旋转及正常绘画；手机系统三指手势冲突的排查方式见前文

「禁用触控」沿用现有操作的含义，会同时停止画布上的手指绘画和手势；需要通过快捷操作浮窗的同一操作恢复触控
