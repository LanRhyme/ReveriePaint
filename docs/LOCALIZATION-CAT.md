# 猫猫语（values-cat）风格规范

> 适用文件: `app/src/main/res/values-cat/strings.xml`
> 语言标识: `cat`（`LanguageManager.AppLanguage.CAT`）
> 增量补全时机: 大版本发版前，或维护者明确要求时（见 `AGENTS.md` §6）

## 1. 定位

猫猫语是**以简体中文为底的中文变体**，口吻是「一只爱画画的小猫在跟你说话」。

- 它是彩蛋语言，不是密码语言：**可读性永远优先于萌度**。用户必须一眼看懂按钮会做什么
- 猫味来自**动作动词、语气词和句子骨架**，不来自给每个名词加「喵」
- 技术名词保持标准中文，见 §4 白名单

## 2. 称呼与语气

| 角色 | 说法 |
|---|---|
| 用户 | 一般用「你」；招呼、鼓励、分享类可用「老大」 |
| 应用自身 | 「小猫」，只在动词句里出现（`小猫在搬作品…`） |
| 笔刷/图层 | 直呼其名，不人格化（`这层被爪爪按住了，改不了`） |

句子规则：

- **不用句号「。」**，结尾用「！」「…」「喵」「喵~」；疑问句尾常加「 喵？」
- 否定用「没 / 不 / 不了」：`没藏好`、`叼不进来`、`拍飞就捡不回来了`
- 失败口语化为「翻车」：`下载翻车了喵`、`存进相册翻车了: %s`
- 进度条/加载用「搬运 / 揉 / 正在…」：`小猫正在搬作品…`、`正在叼来笔刷库…`

## 3. 动作词替换表

替换只在**语义通顺**时生效；动词在句中作名词修饰时保持标准词。

| 标准 | 猫猫语 |
|---|---|
| 确定 / 确认 | 好喵！ |
| 取消 | 算啦（独立按钮）/ 收爪 / 不要了 |
| 完成 | 搞定啦 |
| 保存 | 藏好 / 藏起来 |
| 自动保存 | 悄悄藏好 |
| 删除 | 拍飞 / 一爪拍飞 |
| 导入 | 叼进来 |
| 导出 | 叼出去（有明确目的地时用「叼到 X」） |
| 创建 / 新建 | 揉一个 / 揉张新纸 |
| 复制 | 变个分身 |
| 粘贴 | 贴贴 |
| 撤销 | 倒退一爪 |
| 重做 | 重新抓一爪 / 抓回来 |
| 搜索 | 嗅嗅 / 嗅嗅找找 |
| 清空 | 统统扫光 |
| 关闭 | 关掉 |
| 重置 | 从头再来（面板级重置可保留「重置」） |
| 刷新 | 抖抖毛刷新 |
| 预览 | 瞄一眼 |
| 返回 | 回去（工具栏图标位可保留「返回」） |

## 4. 保持标准中文的白名单

以下类别**不要**萌化，否则会破坏专业可读性或与其他语言文档不一致：

- 混合模式：正常 / 正片叠底 / 滤色 / 叠加 / 变暗 / 变亮 / 差值 / 排除 / 色相 / 饱和度 …
- 工具名：画笔 / 橡皮擦 / 混合涂抹 / 填充 / 圈涂 / 渐变 / 套索选择 / 提色 …
- 图层与色彩术语：图层 / 图层组 / 蒙版 / 不透明度 / 流量 / 间距 / 散布 / 容差 / 羽化 / 色阶 / 曲线
- 滤镜名与参数：高斯模糊 / 锐化 / 波浪 / 浮雕 / 扫描线 …（`filter_name_*` `filter_desc_*` `filter_param_*`）
- 笔刷工作室参数与传感器：`brush_studio_*` `brush_sensor_*` `brush_param_*`（保留 `(English)` 尾注）
- 硬件与型号：OPPO / vivo / iQOO / HUAWEI / HONOR / 小米触控笔型号、`ColorOS`、`S Pen`
- 单位与规格：px / DPI / fps / mm / MB、画幅预设（`create_preset_*` `create_ratio_*`）
- 3D 骨骼与关节名、SRT 时间码规则、WebDAV / Mirror酱 等技术说明
- 品牌与文件格式：Krita / Repaint 引擎名 / PNG / WebP / `.revp` / `.revpbak` / `.myb`

## 5. 标点与表情

- 省略号统一「…」，不用「...」
- 半角括号保留原样（`(默认)`、`(%d 项)`），与简体中文资源保持一致
- 颜文字**总量克制**，全文件保持个位数，只允许：
  - `(ฅ^ω^*ฅ)` 空状态与欢迎
  - `(｡•́︿•̀｡)` 失败（仅 `common_failed` / `failed`）
  - `(=^･ω･^=)` 导出成功
- **禁止**把颜文字或「喵~」塞进句子中间，只放句末

## 6. 硬约束

- 占位符（`%s` `%d` `%1$s` `%%`）数量、顺序、类型必须与 `values/strings.xml` 完全一致
- 短按钮标签（原文 ≤8 字）译文增幅 ≤6 字，避免换行/截断
- 首尾空格必须与简体中文一致（`export_anim_from` / `layer_tag_*_prefix` / `sync_conflict_suffix` 依赖尾空格拼接）
- `\n` 转义、`@` / `?` 开头的特殊字符保持原样
- 不得删除信息量：错误信息里的原因（文件格式、权限、帧号）必须保留

## 7. 反面教材（历史遗留已修）

这些问题在 2026-11 的整理中被批量修掉，新增文案不要再犯：

| 坏味道 | 反例 | 正例 |
|---|---|---|
| 语气词插进动宾之间 | 已经成功藏好啦**到**模板库 | 已经藏进模板库啦 |
| 取消词误当过去式 | 已**算啦**下载 / **算啦**全选 | 下载收爪啦 / 全都不要 |
| 动词替换破坏术语 | 剪切蒙版 → **叼走**蒙版 | 剪切蒙版 |
| 颜文字插句中 | 悄悄藏好搞定啦 喵！(ฅ^ω^*ฅ)**后**在… | 藏好之后在屏幕上弹一条小提示 |
| 重复语气词 | 好喵 喵！ | 好喵！ |
| 名词短语被硬替换 | 已经成功叼进来啦**模板**「%s」 | 模板「%s」叼进来啦 |
| 句号收尾 | 小猫先停爪**。**清一点空间再来 | 小猫先停爪**；**清一点空间再来喵 |
| 半角省略号 | 正在还原数据**...** | 正在还原数据**…** |
| 颜文字串味 | 空状态用失败颜文字 (｡•́︿•̀｡) | 空状态用 (ฅ^ω^*ฅ) |
| 「喵」被逗号截断 | 捡不回来了**喵，**确定吗？ | 捡不回来了，确定要拍飞吗 **喵？** |
| 同一句两种说法 | 这张图叼不进**来了**喵 / 叼不进来喵 | 统一为「这张图叼不进来喵」 |

## 8. 覆盖率现状

全量 3098 键已与 `values/strings.xml` 对齐（0 缺失，含占位符与首尾空格校验）。

其中约 1/3（1044 条）带猫味，其余为上述白名单里的术语、规格与型号——这是**有意为之**，不是漏翻。
判断标准：**这个词在专业绘画软件里是否应当保持行业通用说法**。是 → 保留；否 → 萌化。

颜文字全文件仅 4 处，三种各守各的语义：`home_no_drafts_hint` / `sponsor_empty`（空状态 `(ฅ^ω^*ฅ)`）、
`export_success`（导出成功 `(=^･ω･^=)`）、`failed`（失败 `(｡•́︿•̀｡)`）。语言选择项里的「猫猫语」不带颜文字。

## 9. 增量补全流程

1. 新增/修改 `values/strings.xml` 后，从简体中文取键逐个补 `values-cat/strings.xml`
2. 用脚本核对键齐全性与占位符一致性，例如:

   ```bash
   python3 - <<'PY'
   import re, xml.etree.ElementTree as ET
   def load(p):
       return {s.get('name'): ''.join(s.itertext())
               for s in ET.parse(p).getroot().findall('string')}
   zh  = load('app/src/main/res/values/strings.xml')
   cat = load('app/src/main/res/values-cat/strings.xml')
   FMT = re.compile(r'%(?:\d+\$)?[-#+ 0,(]*\d*(?:\.\d+)?[a-zA-Z%]')
   miss = [k for k in zh if k not in cat]
   bad  = [(k, FMT.findall(zh[k]), FMT.findall(cat[k]))
           for k in zh if k in cat and FMT.findall(zh[k]) != FMT.findall(cat[k])]
   print('missing:', miss)
   print('placeholder mismatch:', bad)
   PY
   ```

3. 用 aapt2 验证资源（不跑整包构建也能验证格式串与转义）:

   ```bash
   ~/Android/Sdk/build-tools/36.1.0/aapt2 compile --dir app/src/main/res -o /tmp/res.zip
   ```

4. 只有大版本发版才需要跑 `./gradlew :app:compileDebugKotlin` 全量机检（见 `AGENTS.md` §13）
