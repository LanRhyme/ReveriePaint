初始基线：`0f67dd29`，1.4.5 适配基线：`5cc4bead`；本轮视口修正基于 #86 的 `c8fe5443`（1.4.6）

## 编辑态视口手势修正（2026-10-08，基于 #86）

#86 的 `c8fe5443` 放开了编辑态的双指平移、缩放，解决控制点被顶部面板遮住后无法移出的问题。
这次补充处理两种边界，不改变单指拖动形状或控制点的入口：

- 原逻辑只在整次手势首次出现双指时记录基准。保留一指、另一指抬起再换位置落下，或三指中原活动指离开时，新指距仍与旧指距比较，导致突然缩放和平移。改为按指针 ID 跟踪活动对，少于两指时清除基准；活动对改变后的第一帧只建立基准，不改变视口。
- 原编辑器未读取视图锁定状态，锁定后仍可缩放。新逻辑与普通画布一致：锁定时保持缩放和旋转，允许平移；使用实际生效的缩放比例补偿质心，避免锁定或缩放到上限时额外漂移。

计算放在纯 Kotlin `QuickShapeViewportGesture` 中，编辑器只负责选择指针和应用结果。
使用相邻事件的屏幕坐标增量，无需重新实现旋转或翻转矩阵，也不触碰文档、录制、C++ 或 JNI。
双指检测不再每帧创建筛选列表；按住轮廓按钮的指针不计入视口手势。
双指结束后剩下的单指仍不拖动形状，全部抬起后再开始新的单指编辑，避免无意挪动草稿。

新增 12 项回归测试覆盖：首次双指、连续平移、2→1→2、指针 ID 重用、三指换对、指针对顺序变化、锁定缩放但允许平移、解锁不补算旧缩放、旋转／翻转／降采样视图的锚点、缩放上下限和无效输入。

## 行为与边界

- 在画布「设置 → 手势」或「绘图辅助」开启「速创形状」，默认关闭，设置跨重启保存
- 使用画笔画出直线、圆、椭圆、矩形或三角形，移动超过 48 dp 后驻笔约 650 ms，收到提示再抬笔进入编辑
- 普通快速抬笔、点按、无法可靠识别的轨迹保持原有绘画流程
- 编辑时拖动画面移动形状；直线端点、三角形顶点可单独调整；圆／椭圆及默认矩形的两个控制点分别用于尺寸和旋转
- 支持圆与椭圆切换、矩形转正方形；确认后是当前栅格图层中的笔画，不是永久保留控制点的矢量图层
- 轮廓提示几何位置，原笔画留作参考；完成时使用当前笔刷替换原笔画，一次撤销移除整条形状
- 规则形状使用原笔画的平均压感和起笔倾角，不逐点保留手绘压感变化
- 「保留原笔画」或系统返回完成原生笔画事务，保留随机纹理、平滑和收笔行为
- 编辑期间拦截底下的工具、图层、时间轴及画布手势；应用进入后台时先保留原笔画，再排队备份
- 喷枪、开启约束的绘图辅助、橡皮、涂抹与液化不启用识别；圆弧只有在单独开启识别选项后参与判断


## 可选编辑增强（2026-10-07）

所有新增行为都有独立持久化开关，初次安装或缺少对应设置键时默认关闭；总开关关闭时仍走普通绘画。
入口与总开关相同，位于「设置 → 手势」和「绘图辅助」。关闭总开关只停用功能，不清除子选项偏好。

| 选项 | 开启后的行为 |
| --- | --- |
| 识别四边形 | 保留四个手绘顶点，不强制直角；关闭八点控制时直接拖动四个角，开启时沿用尺寸／轮廓编辑 |
| 四边形转换 | 编辑四边形、矩形或变形轮廓时，显示转为平行四边形、矩形、正方形的按钮；只改变草稿，完成后提交 |
| 识别三点曲线 | 两端点和位于曲线上的中间点独立可拖动；开启时优先生成三点曲线，不限定为圆弧 |
| 宽松识别 | 容许矩形轻微歪斜和圆钝角，圆弧以全轨迹最小二乘拟合；关闭时保留严格阈值，圆弧识别仍须单独开启 |
| 直线角度吸附 | 识别和拖动端点时，距水平、垂直及 30°、45°、60° 等方向不超过 5° 时吸附；保持固定端点和线长，不影响画布旋转 |
| 识别圆弧 | 验证完整轨迹后识别开放圆弧；两个端点和弧上的第三点可编辑；接近直线、折返、不可靠轨迹仍保留原笔画 |
| 八点尺寸控制 | 矩形四角和四边中点共八个尺寸控制点，另有独立旋转点；角点调整宽高、边中点只调整对应尺寸，对侧保持固定 |
| 按住调整轮廓 | 开启八点控制后显示该选项；编辑时按住按钮，用另一根手指拖动控制点，改变局部轮廓；松开按钮恢复尺寸调整 |
| 曲线轮廓 | 默认关闭，轮廓编辑以直线连接四角；开启后允许弯曲边，也能在编辑栏切换直线／曲线模式 |

默认拖动矩形始终保留直边与直角。按住按钮进入轮廓编辑时：

- 直线模式：拖动角点只改变该顶点，相邻边重新连接；拖动边中点会平移该边两端，四条边始终为直线。
- 曲线模式：四段二次曲线的边中点控制点位于曲线上；拖动角点时保持相邻的曲线辅助控制点，
  可见边中点随角点位移的四分之一移动，避免旧实现因固定中点而向反方向鼓起。拖动边中点则直接调整弧度。
- 两种模式都保留独立旋转点和整体移动、尺寸调整。切回直线模式保留四角位置，清除弧度；再次切回曲线模式从直边开始。

确认后提交为普通栅格笔画，不是可重新打开编辑的矢量对象。轮廓变形不要求增加录制事件或更改 `.revp` 格式。

这一实现借鉴原禁用版本的常用角度与三点圆弧思路，但没有重新启用其宽松的识别回退。
圆弧还会校验全轨迹半径误差、方向、折返和弧长；不把只通过三个点的任意曲线当圆弧。
宽松模式把半径归一化均方根误差从 3.5% 放宽到 7.5%，最大误差从 8% 放宽到 18%；
平滑的非圆弧轨迹若可在误差预算内用圆弧近似，也会被规整，这是宽松模式的有意取舍。
V 形折线、S 形曲线、明显折返和星形仍应回退。矩形只在保留凸性、面积、周长和全轨迹误差检查后，
允许较粗的角点简化与约 30° 的直角偏差。
旧版拟合器以测试专用 `LegacyQuickShapeFitter` 快照保留用于对照，不编入正式应用。

手动验收建议：

1. 关闭总开关和八个子开关，检查普通绘画与原先五类速创形状行为；重启应用检查选项记忆。
2. 开启八点控制，画矩形驻笔后抬笔；拖四角、四边，确认默认保持矩形，且对侧不跳动。
3. 开启轮廓选项，按住「按住调整轮廓」，另一根手指拖边中点或角点；持续按住时可连续调整多个点。
   分别选择「直线轮廓」「曲线轮廓」，将左下角向左下拖动，检查右侧顶点不动、相邻边正确连接。
   松开按钮后再拖控制点应调整整体尺寸；点击完成后检查一次撤销和重做。
4. 单独开启角度吸附，对比接近水平的斜线；单独开启圆弧，对比半圆、折线和不规则轨迹。
   再开关「宽松识别」，对比歪斜矩形、圆钝角、抖动圆弧，同时检查 V 形和 S 形不误识别。
5. 保存重开、查看录制并拖动到开头与结尾，确认颜色、轮廓和位置一致。

## 影响范围

| 范围 | 接入方式与不变量 |
| --- | --- |
| 画笔输入 | 仅开启且符合条件时收集实际发送给引擎的有效采样，不替换常规触摸、平滑或多指手势 |
| 几何识别 | 按弧长重采样，保守判断，未知轨迹返回空结果，不再强制变为直线或矩形 |
| 形状编辑 | 复用 `CanvasViewTransform`，文档坐标与显示缓冲尺寸独立，变换不作为手势生命周期的 key |
| 原生绘制 | 沿用原生笔画事务与批处理接口，原始事务直到确认才取消；全部文档操作在渲染线程 |
| 撤销与录制 | 提交为一次原生笔画；沿用已有笔画事件，不增加录制操作码或文件格式 |
| 设置与生命周期 | 新设置键避免继承历史被禁用功能的旧默认值；编辑期间暂停定时自动保存 |

采样最多 8192 点，超过上限按普通笔画完成。几何路径最多 2049 点，提交时分批直接投递原生引擎，避免挤爆 UI 笔画队列。编辑期间不复制文档像素，不改变双缓冲或 JNI 签名。
