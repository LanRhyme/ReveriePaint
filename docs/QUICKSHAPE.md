# 速创形状实验分支

初始基线：`0f67dd29`，当前适配主线：`8b5b3c20`（1.4.3），分支：`feat/quickshape-editing`

## 行为与边界

- 在画布「设置 → 手势」或「绘图辅助」开启「速创形状」，默认关闭，设置跨重启保存
- 使用画笔画出直线、圆、椭圆、矩形或三角形，移动超过 48 dp 后驻笔约 650 ms，收到提示再抬笔进入编辑
- 普通快速抬笔、点按、无法可靠识别的轨迹保持原有绘画流程
- 编辑时拖动画面移动形状；直线端点、三角形顶点可单独调整；圆／椭圆／矩形的两个控制点分别用于尺寸和旋转
- 支持圆与椭圆切换、矩形转正方形；确认后是当前栅格图层中的笔画，不是永久保留控制点的矢量图层
- 轮廓提示几何位置，原笔画留作参考；完成时使用当前笔刷替换原笔画，一次撤销移除整条形状
- 规则形状使用原笔画的平均压感和起笔倾角，不逐点保留手绘压感变化
- 「保留原笔画」或系统返回完成原生笔画事务，保留随机纹理、平滑和收笔行为
- 编辑期间拦截底下的工具、图层、时间轴及画布手势；应用进入后台时先保留原笔画，再排队备份
- 喷枪、开启约束的绘图辅助、橡皮、涂抹与液化不启用识别；圆弧暂不纳入自动识别

## 影响范围

| 范围 | 接入方式与不变量 |
| --- | --- |
| 画笔输入 | 仅开启且符合条件时收集实际发送给引擎的有效采样，不替换常规触摸、平滑或多指手势 |
| 几何识别 | 按弧长重采样，保守判断，未知轨迹返回空结果，不再强制变为直线或矩形 |
| 形状编辑 | 复用 `CanvasViewTransform`，文档坐标与显示缓冲尺寸独立，变换不作为手势生命周期的 key |
| 原生绘制 | 沿用原生笔画事务与批处理接口，原始事务直到确认才取消；全部文档操作在渲染线程 |
| 撤销与录制 | 提交为一次原生笔画；沿用已有笔画事件，不增加录制操作码或文件格式 |
| 设置与生命周期 | 新设置键避免继承历史被禁用功能的旧默认值；编辑期间暂停定时自动保存 |

采样最多 8192 点，超过上限按普通笔画完成。几何路径最多 2049 点，提交时分批直接投递原生引擎，避免挤爆 UI 笔画队列。编辑期间不复制文档像素，不改变双缓冲或 JNI 签名。

## 验收

自动测试覆盖：多尺度圆、采样密度变化、倾斜椭圆与矩形、三角形、不规则／自交轨迹、无效坐标、移动、控制点、闭合路径和输入上限。

真机检查：

1. 关闭功能画普通笔画、二指缩放旋转和撤销，行为应保持原样
2. 开启后分别画五类形状，驻笔并抬笔，尝试移动、控制点调整和类型切换
3. 缩放、旋转画布后重复第 2 步，预览与最终笔画的位置应一致
4. 确认形状后撤销、重做，检查一次撤销只移除这一形状
5. 使用带纹理或压感的笔刷选择「保留原笔画」，检查原轨迹与收笔
6. 保持选区、透明度锁定或剪贴蒙版时绘制，检查结果遵守图层约束
7. 编辑时切到后台、返回，检查原笔画保留；确认后保存、重开和回放

## 实验验证记录（2026-10-04）

- Kotlin 编译和 Debug APK 构建通过
- 490 项 JVM 单元测试通过，包含 17 项 QuickShape 几何、识别及采样测试
- Android API 30 模拟器：驻笔识别并提交到原生像素、一次撤销／重做、快速抬笔／未知轨迹／关闭开关的回退、设置重新读取通过
- 普通直线与驻笔后「保留原笔画」的最终像素一致；窗口触控注入验证了编辑器的移动、缩放和完成按钮
- 最终测试包的「设置 → 手势 → 速创形状」入口已通过界面检查
- 全项目 Lint 报告有 131 个错误、569 个警告、35 个提示；按改动行核对未发现本次新增错误，有一条 `UseKtx` 建议，因此不能称为全项目 Lint 通过
- 回放精确像素对比未通过：规则形状与普通手绘基线都出现边缘像素差异，仍需通过完整回放流程和实际笔刷进一步验证
- 保存重开测试被模拟器 ARM 转译层的 `SIGILL / Undefined instruction` 中断；关闭 QuickShape 保存普通笔画也出现相同错误，尚不能据此判断真机表现
- 未操作真机，带纹理笔刷、选区／特殊图层和后台恢复仍需手动回归

实验状态：默认关闭，尚未提交 PR，不能作为已完成全面回归的发布版本。
