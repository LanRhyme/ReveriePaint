# 快捷图层操作与属性入口（#92）

## 问题与范围

快捷图层浮窗已有新建图层、图层组、选择与显隐操作，也能显示剪切状态，
但缺少剪切蒙版、继承透明度的操作入口；选中图层后也无法直接进入属性页。
本次仅补齐这些入口，不修改引擎、录制格式或工程文件。

## 实现与取舍

- 在原拖动栏下增加一行剪切蒙版、继承透明度与属性图标。保留 156dp 浮窗宽度，
  新增按钮使用 48dp 触控区域，不通过缩小关闭按钮或拖动手柄挤入操作。
- 首次点击未选图层只切换选择；再次点击已选图层或点击属性图标，进入已有完整图层面板的属性页。
  没有在 156dp 浮窗内复制一套属性编辑器。原浮窗开关与位置不变，关闭完整面板即可继续使用。
- 新增入口通过 `PaintViewModel.setLayerClipped` / `setLayerAlphaInherited` 操作，
  复用主线撤销、录制、互斥切换及刷新逻辑。按钮状态直接来自 `vm.layers`，不维护乐观开关副本。
- 背景、无有效选择及四类蒙版节点禁用透明度操作。剪切是否有可依附的下方同级节点仍由引擎判定。
- 属性导航携带图层稳定 ID，进入面板时再解析索引；目标已删除时回退图层列表。
  导航请求消费后清空，以便同一图层重复打开，以及完整面板已固定时切换属性目标。
- 新增的 LayerPanel 参数带默认值，原工具栏和滤镜入口保持原路径；继续使用现有中英文资源、图标与主题色。
- 低高度窗口限制图层列表高度，使新增操作行不挤出屏幕。大字体、横屏及平板仍需设备检查。

## 影响范围与复查要点

影响快捷图层行点击、浮窗操作栏、绘画页导航与完整图层面板的可选初始属性入口。
没有直接从 UI 调用 JNI，没有修改绘制热路径或双缓冲。

本次只在入口解析稳定 ID，未重构完整图层面板原有的所有索引导航。
请特别复查属性页打开期间删除、合并和撤销，以及已经固定的完整面板与快捷浮窗同时存在的情形。

## 手测流程

1. 安装独立测试包 `com.reverie.paint.issue92test`，新建小画布并打开“快捷图层”。
   原有新建图层、图层组、眼睛显隐和拖动位置应正常。
2. 新建上下两层，在下层画色块、上层画超出色块边缘的笔迹。选中上层，点击剪切图标，
   上层内容应受下层形状限制；关闭开关后恢复。按钮高亮与完整图层面板应一致。
3. 切换继承透明度，再切回剪切蒙版。检查两者互斥、撤销与重做后的两个按钮状态和画布效果；
   更换图层后不能沿用上一个图层的高亮。
4. 点击另一个图层应仅选中；再次点击它应打开对应属性页。属性图标应能直接进入当前图层属性。
   调整名称、不透明度、混合模式，返回图层列表再关闭面板，浮窗保持原位置且数据显示同步。
5. 对背景层和蒙版节点检查快捷开关禁用；背景属性页仍可打开。
   对组、填充层和滤镜层检查打开的是正确属性页，没有误操作其他图层。
6. 固定完整图层面板，再从浮窗打开另一图层的属性；删除图层后撤销，再次进入属性应对应正确目标。
   普通图层按钮打开列表、滤镜快捷入口打开滤镜页的原有行为也应正常。
7. 横屏、分屏或放大字体后检查操作行、关闭按钮、列表滚动及浮窗拖动。
   保存退出重进，检查图层状态与浮窗位置；如需验证录制，另比较两种透明度开关及互切的回放。
