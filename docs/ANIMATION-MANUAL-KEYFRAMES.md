# 可选的手动建帧流程

对应 [#54](https://github.com/LanRhyme/ReveriePaint/issues/54)。时间轴设置中的“手动建帧”默认关闭，
作为本机作画偏好保存，切换文档不重置，不改变 `.revp` 格式。

- 关闭：沿用原有行为，在没有关键帧的位置落笔会自动新建空白帧。
- 开启：延长区间使用同一张画，落笔修改整段曝光，不自动拆分。拖动帧块右边缘调整显示时长。
- “新建空白帧”使用现有建帧命令；当前位置已有关键帧时，沿用向后找空位的规则。
- “旧帧参考”独立开启，使用上一关键帧的洋葱皮预设，初始不透明度 96/255，可继续调整透明度和着色。
  关闭再开启会保留这些调整；切换作画方式不会修改洋葱皮配置。
- 动画导出期间隐藏参考，成功、失败或取消后恢复显示条件和当前帧。

## 验收流程

1. 新建动画画布，画一个红色圆。确认手动建帧默认关闭，在后续没有关键帧的位置落笔会建空白帧。
2. 开启手动建帧，选一张画并拖动右边缘延长到 6 帧。移动播放头查看整段，应保持同一张画。
3. 在延长区间补一笔：关键帧数量不变，整段画面一起变化。撤销、重做应恢复同一张画的内容。
4. 在所需位置点“新建空白帧”，画一个蓝色方形；回到红色圆所在帧，确认没有被这一笔修改。
5. 在新帧开启旧帧参考，应淡化显示红色圆。调整透明度，然后关闭、重新开启，确认透明度保留。
6. 开着参考导出 PNG 序列，逐帧查看：延长区间重复前一张，新空白帧没有红色残影；回到画布参考仍显示。
7. 关闭手动建帧，在后续没有关键帧的位置落笔，确认恢复自动建空白帧，已有帧不被改写。
8. 重启应用确认作画方式选择保留；新建静态画布确认正常绘制，没有自动开启动画通道。

## 影响范围

只调整笔画开始前的建帧策略、时间轴入口和动画导出的参考显示门控。
引擎操作继续在渲染线程串行执行，复用现有曝光拉伸与洋葱皮，不增加像素副本或 JNI 接口。
普通绘画、帧复制、工程格式、时间轴拖动识别保持原有实现。

完整切帧流程依赖 [#53](https://github.com/LanRhyme/ReveriePaint/pull/53) 的修复；
本功能分支不重复包含该 PR 的 C++ 或预编译库。
