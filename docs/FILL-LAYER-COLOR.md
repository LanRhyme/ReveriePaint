# 填充图层换色修复

对应 Issue #47，基于 1.4.1（`0957fe4e`）。

## 原因与修复

图层设置的换色按钮通过 `fillLayerForeground` 调用 `ReverieCore::fillLayer`。原实现用 `KisFillPainter::paintRect`，但没有设置填充样式或笔刷实例。实际依赖的 Krita 实现默认 `FillStyleNone`、`paintOp == nullptr`，既不填充内部，也不绘制边缘，结果是颜色不变。

- 使用 `fillSelection` 写入颜色。该接口经 `bitBlt` 合成，继续处理选区、透明度锁定和混合，不依赖笔刷实例。
- 颜色按目标设备的色彩空间构造；不透明度仅应用在 painter 上，避免 50% 被重复相乘成 25%。
- 保留原有事务、撤销、重做及图层可编辑性检查。
- 填色前记录当前颜色和不透明度，复用现有 `CONTEXT` 事件，避免两笔之间换色后回放仍使用旧值；录制格式及 JNI 签名不变。

本次保持现有填色语义：使用当前前景色和笔刷不透明度，有选区时只影响选区，透明度锁定时保留 alpha。填充层仍沿用预填色颜料层实现。

## 影响范围

- 图层设置中的更改填充颜色。
- `L_FILL_LAYER` 录制回放。
- 该操作的选区、透明度锁定、普通锁定和撤销重做。

油漆桶继续走原有 `floodFillAt`，图层类型识别由独立修复处理。

## 手机回归步骤

1. 笔刷不透明度设为 100%，清除选区；新建蓝色填充层，从图层设置换成红色，检查全层立即变红。
2. 撤销一次应恢复蓝色，重做一次恢复红色；连续换几次颜色，每次都能独立撤销。
3. 在白色填充层上，以 50% 不透明度填黑色，应得到约中灰，而非约 75% 亮度的浅灰。
4. 框选半边画布后换色，检查只有选区内部变化；清除选区后换色应作用于整个画布范围。
5. 在有透明区域的图层上开启透明度锁定，换色后原透明区域保持透明；普通图层锁定后填色不应改变像素。
6. 保存 `.revp`，退出再打开，检查颜色；播放绘画过程，检查换色及不透明度与实际操作一致。
