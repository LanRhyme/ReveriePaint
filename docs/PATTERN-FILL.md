# 图案填充（#48）

分支 `feat/pattern-fill`，原始实现基于 `49f08196`，本次适配主线 v1.4.4（`659d1d1e`）。功能范围、兼容边界及验证结果如下。

## 功能与边界

- 油漆桶左侧新增图案入口，可从本地图库导入图片或选择应用 `patterns` 目录已有的 PNG/JPG/JPEG；选择“改用前景色”恢复原来的纯色填充。
- 填充图层设置新增“选择填充图案”；图层混合模式和不透明度继续使用现有图层属性。纯色选择器仍可将图案换回颜色。
- 油漆桶在图案模式下使用独立的不透明度和混合模式，保留当前层/全部层采样、容差、扩展、羽化、闭合空隙、选区及透明度锁定。
- 图片导入在 IO 线程执行，转换为 PNG；最长边最多 2048 像素，编码后最多 16 MiB，保留透明通道。选择图案后可等比缩放 10%–400%（同时受 2048 像素上限约束）；100% 为导入尺寸，图库原图不变。暂不提供旋转、偏移和 PAT 文件浏览。
- 缩放默认“清晰边缘”（最近邻），保留像素图和线稿的硬边缘；可选“平滑”（双线性），适合照片和连续纹理。最近邻缩小可能丢失细线，放大可能出现锯齿；两种方式都不能恢复导入前已丢失的细节。预览读取导入后的完整图像，实际应用在 IO 线程生成 PNG，沿用既有图案录制事件。
- 主线新建填充图层仍为带类型标记的颜料层，图案结果随工程像素保存；旧工程的生成器图层使用独立图案生成器，PNG 嵌入图层配置，不依赖外部文件路径。损坏的生成器图案配置回退到工程内逐层 PNG 备份。

## 影响范围与兼容

新增 JNI `setFillLayerPattern`、`floodFillPatternAt`，原接口签名不变。文档操作继续排入引擎线程，不修改绘画手势、渲染双缓冲、动画运动关键帧或 QuickShape。

生成器配置增加可撤销的切换，覆盖图案与纯色互换；颜料填充层及油漆桶使用像素事务。整层替换只使用图层自身混合/不透明度，不叠加画笔属性。

录制增加 `T_PATTERN_FILL = 47`，包含显式目标图层、整层/连通区标记、填充参数、混合模式、不透明度和 PNG。连续使用同一图案时复用上一个图案字节；新会话首先写完整 PNG，拖动回放进度时清空缓存并从事件流重建。原有纯色事件保持原有读取路径。旧版本不认识新事件，不能用来回放包含图案填充的新录制；项目原有录制大小上限仍为 32 MiB，频繁切换大图案会较快达到上限。

## 手动验收

1. 导入一张带透明部分的 PNG 和一张 JPG。关闭选择器后重新打开，确认图库中仍能选择两张图片；取消系统图片选择器不会更改当前图案。
2. 新建填充图层并选择图案，确认平铺和透明区域。改变图层不透明度与混合模式；撤销/重做图案填充，再切换纯色并撤销。
3. 普通图层画两个闭合区域，油漆桶选择图案，分别测试当前层和全部层采样，确认只填中所点区域。
4. 限定选区、锁定透明度后再填充，检查选区外像素及原透明度；测试 50% 不透明度和正片叠底。
5. 保存 `.revp`、离开并重新打开，确认颜色、透明度和图层属性保持一致。回放混合使用纯色与图案的操作，反复拖动回放进度，确认无需重新导入原图片。
6. 油漆桶切回前景色，确认旧的纯色填充仍可使用；锁定图层、无效图片不应留下像素修改。

### 其余问题及处理经验

- **有效 PNG 被拒绝**：初版 Qt 图片尺寸预检在当前无 GUI 运行环境中拒绝有效测试图。改用已链接的 libpng 解码，重建后真机验证。不能将解码成功与否仅归因于用户图片损坏。
- **构建环境不稳定**：原生开发期间 Docker 曾多次因残留套接字访问失败而无法启动，恢复引擎后继续构建；Kotlin/Lint 曾因内存不足退出，降低并发并拆分构建步骤后完成。环境启动失败不算业务测试失败，也不算测试通过。
- **早期 APK 验证局限**：初版全量打包遇到磁盘 I/O 停滞，临时以已有开发 APK 替换已重建 JNI 库作运行验证。后续 v1.4.4 适配已使用完整 Gradle 构建，并校验包内所有原生库，不能将临时包结果冒充最终产物验证。
- **旧生成器工程缺样本**：人工构造的生成器样本在主线也于填充前显示空白，不能据此认定是图案功能回归。新建颜料填充层路径已有验证，真实旧生成器工程仍需维护者提供样本补测。
- **设备连接和操作干扰**：USB 调试曾未被识别，恢复后才进行真机回归；缩放弹窗自动操作与手测重叠时出现退出，已作废该段 UI 结果，并按提交者要求停止操作手机，不将其记为应用缺陷或重置功能通过。

### 新增复查步骤（请其他维护者独立验证）

1. 用 2×2 或 8×8 像素、无渐变的棋盘格/色块 PNG，选择 400% 和默认“清晰边缘”后填充。在画布 100% 缩放下检查相邻色块边界，不应产生平滑过渡；切换“平滑”重复填充，应出现插值过渡。不要把画布视口自身放大后的显示插值当作图案像素变化，必要时导出后逐像素比较。
2. 两种模式分别设置 50%、100%、200%，核对尺寸、透明通道和取消行为；重置恢复导入尺寸，重新选择图片仍从原尺寸开始，图库不会多出缩放副本。最近邻缩小丢失细线及非整数倍放大的阶梯边缘属于取样特性。
3. 分别走油漆桶及填充图层入口，测试撤销重做、保存重开、混合纯色/图案录制及拖动回放进度。新事件直接保存处理后的 PNG，回放不需要重新选择缩放模式。
4. 在竖屏、横屏及较大字体下检查弹窗滚动、模式选择、重置、应用与取消；照片用平滑模式，线稿用清晰边缘，补充不同设备的视觉反馈。
