# 图案填充（#48）

分支 `feat/pattern-fill`，原始实现基于 `49f08196`，本次适配主线 v1.4.4（`659d1d1e`）。功能范围、兼容边界及验证结果如下。

## 功能与边界

- 油漆桶左侧新增图案入口，可从本地图库导入图片或选择应用 `patterns` 目录已有的 PNG/JPG/JPEG；选择“改用前景色”恢复原来的纯色填充。
- 填充图层设置新增“选择填充图案”；图层混合模式和不透明度继续使用现有图层属性。纯色选择器仍可将图案换回颜色。
- 油漆桶在图案模式下使用独立的不透明度和混合模式，保留当前层/全部层采样、容差、扩展、羽化、闭合空隙、选区及透明度锁定。
- 图片导入在 IO 线程执行，转换为 PNG；最长边最多 2048 像素，编码后最多 16 MiB，保留透明通道。图案以导入后的像素尺寸平铺，暂不提供缩放、旋转、偏移和 PAT 文件浏览。
- 主线新建填充图层仍为带类型标记的颜料层，图案结果随工程像素保存；旧工程的生成器图层使用独立图案生成器，PNG 嵌入图层配置，不依赖外部文件路径。损坏的生成器图案配置回退到工程内逐层 PNG 备份。

## 影响范围与兼容

新增 JNI `setFillLayerPattern`、`floodFillPatternAt`，原接口签名不变。文档操作继续排入引擎线程，不修改绘画手势、渲染双缓冲、动画运动关键帧或 QuickShape。

生成器配置增加可撤销的切换，覆盖图案与纯色互换；颜料填充层及油漆桶使用像素事务。整层替换只使用图层自身混合/不透明度，不叠加画笔属性。

录制增加 `T_PATTERN_FILL = 47`，包含显式目标图层、整层/连通区标记、填充参数、混合模式、不透明度和 PNG。连续使用同一图案时复用上一个图案字节；新会话首先写完整 PNG，拖动回放进度时清空缓存并从事件流重建。原有纯色事件保持原有读取路径。旧版本不认识新事件，不能用来回放包含图案填充的新录制；项目原有录制大小上限仍为 32 MiB，频繁切换大图案会较快达到上限。

## 手动验收

1. 导入一张带透明部分的 PNG 和一张 JPG。关闭选择器后重新打开，确认图库中仍能选择两张图片；取消系统图片选择器不会更改当前图案。
2. 新建填充图层并选择图案，确认平铺和透明区域。改变图层不透明度与混合模式；撤销/重做图案填充，再切换纯色并撤销。
3. 普通图层画两个闭合区域，油漆桶选择图案，分别测试当前层和全部层采样，确认只填中所点区域。
4. 限定选区、锁定透明度后再填充，检查选区外像素及原透明度；测试 50% 不透明度和正片叠底。
5. 保存 `.revp`、离开并重新打开，确认颜色、透明度和图层属性保持一致。回放混合使用纯色与图案的操作，反复拖动回放进度，确认无需重新导入原图片。
6. 油漆桶切回前景色，确认旧的纯色填充仍可使用；锁定图层、无效图片不应留下像素修改。
