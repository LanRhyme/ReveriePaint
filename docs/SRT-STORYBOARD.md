# SRT 单帧分镜（当前版本）

## 使用

动画画布 → 时间轴设置 → 导入 SRT 分镜。每条字幕按顺序生成一个关键帧，默认长度为 1 帧，从第 0 帧连续排列；不插入原时间中的间隙或额外结束帧。字幕起止时间仅保留为文本参考。

选中分镜，拖动帧格右侧手柄可调整曝光时长；后面的分镜随之顺延。字幕按脚本顺序对应当前轨道关键帧，拉长、缩短及撤销后重新读取引擎关键帧位置。SRT 轨道落笔不会自动生成新关键帧；普通图层和原有“手动建帧”设置不改变。

字幕栏可打开列表并跳转。主动新增/删除关键帧导致数量与字幕不一致时，暂停字幕自动定位并提示，避免给画面配错字幕；恢复数量后恢复按序对应。拖动重排画面后字幕仍按脚本顺序排列，不为画面重新排序字幕。

重新导入会新增轨道并替换当前字幕参考。旧版工程仍按旧时间映射打开，不自动压缩已有绘画；要使用“一字幕一帧”，请重新导入 SRT（建议在新动画画布中导入）。旧版默认命名的 SRT 轨道也会关闭落笔自动切帧；已手动改名且未存有轨道绑定的旧工程无法自动识别。

保存为 REVP。模式与关联轨道下标写入 `reverie.anim.storyboard.srt.layout` 和 `.track` 资源；运行中使用引擎图层 ID 跟踪，下标随图层结构同步更新。C++/JNI 与原生库不修改。

## 输入与兼容性

- 支持 UTF-8（可带 BOM）、带 BOM 的 UTF-16、逗号或小数点毫秒分隔符、常见换行与多行字幕
- 最多 1 MB、1000 条字幕；按原始开始时间排序，拒绝空字幕、无效时间和重叠字幕
- 字幕作为参考文本保存，不绘制到画布，也不烧录到导出的视频或图片；仅保证 REVP 保留参考数据
- 再次导入新增轨道并替换当前参考列表，已有绘画保留；仅当前绑定轨道禁止落笔自动建帧
- 手动增删关键帧后，数量不匹配时暂停自动定位；重排画面不会重排脚本文字
- 原有播放范围保持不变，需要时使用既有播放范围设置调整
- 字幕资源不参与绘画撤销；撤销或删除关联轨道后参考列表仍可查看

## 影响范围与实现约束

- `AnimationState.reset` 清空字幕状态，并递增代际号以丢弃旧工程的异步读取结果
- `syncAnimationFromNative` 读取当前关键帧及末帧曝光，更新字幕映射；`syncLayersFromNative` 按图层 ID 更新持久化下标，覆盖图层增删、移动、重命名路径
- `ensureKeyframeForPaintOnRenderThread` 仅对绑定的 SRT 轨道跳过自动建帧，普通动画图层保持既有行为
- UI 入口和参考栏为独立 Composable，无字幕时不占空间；新增文案有中英文资源
- 文件读取与解析在 IO 线程，所有引擎操作通过 `runCore` 在渲染线程执行；复用媒体导入忙状态
- 新资源使用 `reverie.anim.` 命名空间，现有音频资源过滤规则会排除它们
- 解析完成后才创建轨道；创建失败仅移除本次新建图层并恢复原图层与播放头

### 原生调用约束

建层与移动必须在撤销宏之外执行。`beginUndoMacro` 持有图像 barrier lock，而结构操作会等待投影刷新；将两者嵌套会导致导入阻塞，后续保存也无法执行。仅批量创建关键帧包在撤销宏中。

移动到顶层时显式指定最上方根级兄弟图层。预编译引擎的 `moveLayerAbove(layer, -1)` 会将节点插入背景位置，导致启用动画失败，因此本功能不使用该插入语义。

## 验证方式

```sh
./scripts/copy_jni_libs.sh
./gradlew :app:compileDebugKotlin :app:testDebugUnitTest :app:assembleDebug
```

`SrtStoryboardTest` 覆盖编码、解析、排序、无效/超限输入、原始时间存储往返、单帧规划、曝光调整与关键帧数量不匹配。`AnimationStateResetTest` 覆盖切换工程时字幕状态和异步令牌重置。

Android 手动回归使用 `docs/examples/storyboard.srt`：

1. 新建动画画布，导入三条示例字幕，应只有三个连续关键帧（0、1、2）
2. 将第一格右边缘拉长到 5 帧，在内部第 3 帧绘画，应仍只有三个关键帧（0、5、6）
3. 点击第二条字幕，应跳到第 6 帧（内部帧号 5）
4. 保存退出、重开工程并继续在第一格内部绘画，字幕与画面应保留且不切分
5. 切换普通动画图层，在没有关键帧的位置绘画，应保持原有自动建帧行为
6. 检查无效文件提示、撤销/重做、图层移动/删除和新建工程后的状态清理
