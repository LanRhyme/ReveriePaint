# 图层列表交互：Mangar 对照与行内控件

参考对象：<https://github.com/NikuKikai/Mangar>（iPadOS / SwiftUI 的漫画绘画应用）。
本次只改图层列表面板的行内交互，不碰引擎、录制格式与工程文件。

## Mangar 图层面板的做法

`Mangar/ContentView.swift`（`layerList` / `layerRow` / `dropTarget` 一段）与
`Mangar/UI/VerticalDragProperty.swift`、`LayerNameControl.swift` 里，有几点和本项目
现有实现不同：

| 交互 | Mangar 的做法 | 本项目的做法（改造前） |
| --- | --- | --- |
| 行高信息密度 | 35pt 行内塞进 眼睛 / 缩略图 / 蒙版缩略图 / 名称 / 混合模式 / 不透明度 / 视差 z / 效果标记 | 52dp 行内只有 眼睛 / 缩略图 / 名称 / 状态标记；不透明度与混合模式在详情页 |
| 属性调节 | 行内小药丸上下拖动直接改值（`VerticalDragProperty`，数字 200pt 走满量程，枚举每 24pt 一档并在浮层里高亮候选） | 点图层进入详情页，拖动滑杆；混合模式还要再进一个子页 |
| 排序 | 行尾固定拖拽手柄（`line.3.horizontal`），位移 4pt 立即开始拖动，拖动中左右位移选择落点层级 | 长按任意位置 300ms 后拖动；左右位移只有"保持/脱离图层组"两档 |
| 落点预览 | 自定义落点线 + 树线高亮目标父组 + 文件夹行中段高亮"放进组" | 已有：浮动卡片 + 带缩进的落点线 + 目标组放大描边 |
| 可见性 | 眼睛按"实际参与合成"上色：父组隐藏时画灰 | 子层眼睛恒亮，父组隐藏时看不出来 |
| 选中 | shift / command 多选，主选强调色、次选灰 | 已有：右滑多选 + 强调色/次级底色 |
| 重命名 | 行内直接编辑；上下拖动在预设名称里挑 | 双击名称弹对话框 |

真正值得抄的是前四条里的**"行内调值"**与**"显式拖拽手柄"**，以及**眼睛的
有效可见性**。其余（预设名称、shift/command、蒙版缩略图编辑目标）与本项目
的图层模型（蒙版是独立行、平板无键盘修饰键）不匹配，没有跟。

## 本次落地的三件事

### 1. 行内不透明度药丸（`LayerRowControls.kt` / `model/LayerRowInteractionMath.kt`）

图层行第二行从一段静态文字 `45% · 正片叠底` 改成 `[类型标签] [45% 药丸] [混合模式]`：

- 药丸**横向拖动**直接改本层不透明度，拖动中实时预览，松手才提交（一次拖动 =
  一步撤销），节流 40ms（引擎侧还有 16ms 渲染节流）。
- 滤镜/调整层（`nodeType == 3`）拖动中**不**逐帧预览：引擎的
  `ReverieCore::setLayerOpacity` 对这类层走整棵投影重合成
  （`recompositeProjection`，见 issue #139），逐帧调用会顶住引擎线程。这类层
  拖动只更新行内数值，松手提交一次（详情页滑杆行为未改）。
- 方向取横向而不是 Mangar 的纵向，是本项目可滚动面板的既有约定：`ReSlider`
  在 `LazyColumn` 里就是"纵向让给滚动，横向才认领"。纵向调节在列表里必然
  和滚动抢手势，横向不会。
- 数值 100% 时药丸是中性灰，非 100% 时整体转强调色，一眼能看出哪些层被调过。
- 详情页滑杆保留，作为精确调节与无障碍入口。

### 2. 行尾拖拽手柄（`LayerDragHandle`）

- 22dp 宽的三横线抓手，位移超过 touch slop 立刻进入拖动，不用再等 300ms 长按。
- 长按任意位置拖动仍然保留（老手路径不变），手柄只是把"能不能拖"变成看得见的。
- 手柄与药丸都登记到 `LayerRowPressGate`：手指落在它们上面时，行的 300ms
  长按拖动不启动，避免"按住药丸想调值，结果整层被拖走"。

### 3. 父组隐藏时的眼睛变暗（`layersHiddenByHiddenGroup`）

- 图层镜像里只有节点自身的可见性，没有"实际是否参与合成"。列表按引擎层序遍历
  一次性算出"自身可见但祖先隐藏"的集合，眼睛画暗、无障碍描述改成"所在图层组已隐藏"。
- 纯函数在 `model/LayerRowInteractionMath.kt`，有 `LayerRowInteractionMathTest` 覆盖
  嵌套组、隐藏组的兄弟子树、蒙版深度、深度跳跃等边界。

### 4. 行内混合模式直达（`LayerBlendModeChip`）

- 第二行的混合模式从"只在非正常时显示的纯文本"变成可点的药丸：点一下直接进
  混合模式选择页（原来要点行选中 → 再点进详情 → 点混合模式，三步）。
- 从列表行内进来的，返回时回列表；从详情页进来的仍回详情页（`LayerView.BlendModes`
  的 `fromList` 标记）。
- 背景层（引擎恒为"正常"）、蒙版（没有混合模式）、分格组行（走自己的面板工具）
  不挂入口，退回纯文本，避免点了没反应。
- 不做拖动切换：换混合模式没有预览接口，逐帧 `setLayerBlendMode` 会走节点级
  重合成（`markNodeDirtyAndFlush`），快速试模式走选择页点选更稳。

### 5. 药丸的水位填充（Mangar 的 `ControlValueLevel`）

- 药丸底部按不透明度数值高度填充，交界处 1dp 水线；0% 与 100% 两端不画水线，
  免得看起来像描边。不读数字也能扫出"哪几层被调淡了"。
- 填充色跟随状态：拖动中强调色（alpha 0.26）、非 100% 强调色（0.14）、
  100% 用中性灰（0.12），配合文字颜色区分"被调过"与"没动过"。

## 手势共存约定（改这块前必读）

行本身有一个 300ms 长的自定义手势状态机（点击 / 长按拖动 / 左右滑抽屉 / 右滑多选），
行内控件接入不能破坏它。三条规则：

1. **子控件先认领、只消费位移**：Compose 的 Main pass 由内向外，行内控件的
   `pointerInput` 先拿到事件；认领后 `change.consume()`，行在看到
   `change.isConsumed` 时直接退出判定（`LayerRow` Phase 1 里 `return 3`）。
   松手事件不消费，行的 `changedToUpIgnoreConsumed()` 判定保持原语义。
2. **纵向位移让给滚动**：控件的认领条件是 `abs(dx) > touchSlop && abs(dx) >= abs(dy)`，
   纵向占优就完全不消费，交给 `LazyColumn`。
3. **按下即登记**：`LayerRowPressGate.pressedInside` 在 down 时置位、手势结束清位；
   行长按拖动在 300ms 到期时检查这个标记。

## 影响范围与复查要点

改动涉及：`LayerRow.kt`（手势状态机 + 行内容）、`LayerRowControls.kt`（新增）、
`LayerListView.kt`（有效可见性集合）、`LayerDragOverlay.kt`（卡片上的静态手柄）、
`model/LayerRowInteractionMath.kt`（新增）与中英文案。

复查重点：

- 轻点选中 / 再次轻点进详情、双击名称重命名、长按拖动、左滑抽屉、右滑多选、
  双指捏合合并 —— 一条都不能被行内控件抢掉。
- 分格组行（`panelIdForGroupRow` 非空）与分格裁剪蒙版行（`panelCropStateFor` 非空）
  不显示不透明度药丸：前者的显隐/裁剪语义特殊，后者没有独立不透明度。
- 背景行不显示拖拽手柄（背景不可拖动），但仍可调不透明度。
- 拖动中行内的药丸不应改值：拖动开始后手指已经离开行，正常不会触发；
  卡片上的药丸是纯静态显示。
- 引擎调用只走 `setLayerOpacity(preview/direct)`，不进 JNI 热路径，不改双缓冲。

## 手测流程

1. 新建 3~4 层（含一个图层组、一个蒙版）。列表第二行应显示 `[45%] [正片叠底]` 样式；
   100% 且正常混合时只显示中性灰的 `100%`。
2. 横向拖动某一层的 `100%` 药丸，画布应实时变透明，松手后撤销一次回到 100%。
   纵向拖动药丸应滚动列表，数值不变。
3. 药丸上按住不动 0.5s 再横向拖动：不应触发图层拖动排序。
4. 按住行尾三横线手柄直接拖动：图层应立刻跟手并可插入到组内；松手落位。
   长按行中间拖动仍然可用（老路径）。
5. 隐藏一个图层组：组内子层的眼睛应变暗，无障碍朗读为"所在图层组已隐藏"；
   重新显示组后恢复。
6. 左滑抽屉、右滑多选、双指捏合合并、双击名称改名逐条回归。

## 已做过的真机验证 (OPD2413 / Android 16, debug 包)

- 药丸横向拖动 100% -> 77%，画布像素随之变亮；撤销一次精确回到 100%（眼睛
  与药丸配色同时恢复中性）。验证了 `commitLayerOpacityScrub` 的"先退回起手值
  再提交"确实让撤销旧值等于拖动前的值。
- 药丸上纵向拖动：数值保持 100%，列表位移，没有误调。
- 轻点药丸：只选中该层（不透明度不变）；再点一次进详情页（原有语义未变）。
- 行尾手柄直接拖动：图层立即跟手，可重排、也可拖进图层组（落点线 + 组高亮生效）。
- 左滑抽屉（复制/独显/删除）、右滑多选、眼睛显隐均回归正常。
- 隐藏图层组后，组内子层眼睛亮度峰值 113 vs 普通行 174（同一像素区域采样），
  "父组隐藏"提示按预期变暗。
- 第二轮：拖到 83% 后药丸呈现"上 17% 暗、下 83% 亮"的水位；点行内 `[正常]`
  直接进混合模式页，`[100%] [正常]` 两枚药丸在 52dp 行高下不挤；背景行只有
  不透明度药丸。

未覆盖：双指捏合合并、长按拖动（合成输入难以稳定复现 300ms 长按窗口）、
含分格组/分格蒙版的文档、滤镜/调整层的不透明度拖动（只做了代码路径上的
预览抑制）。

## 其他参考项（看过但本轮没做）

| Mangar | 本项目现状 | 判断 |
| --- | --- | --- |
| 标尺（ADR 0015：随画布旋转、1/2/5 刻度、px/mm） | 无 | 真缺功能，但要啃旋转/翻转/缩放的坐标变换，单独一轮 |
| 导航缩略图（视口四边形、点按定位、1:1、回正） | 有缩放%/旋转 HUD 与 1:1/回正快捷键，无缩略图 | 需要低频全图预览位图（引擎侧采样），工程量最大 |
| 眼睛按"视口内有内容"高亮 | 只有父组隐藏变暗（已做） | `contentBoundsLayers` 只返回多层并集；逐层要加批量 JNI/改 C++ |
| 拖动属性的浮动数值提示 | 拖药丸时数字被手指挡住 | 需要面板级浮层跨组件传状态，收益中等 |
| ScrubbableToggle（点按开关 + 拖动调强度） | 行内调值已有药丸 | 成对的"开关+强度"控件不多，收益小 |
| SlideOutButton（点=动作 / 向下滑=展开参数） | 无同类 | 隐藏手势，平板可发现性差 |
| 压感曲线 5 点单调三次插值 | 已有 `PressureCurveEditor` | 已有，不用抄 |
