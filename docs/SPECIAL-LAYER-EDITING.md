# 特殊图层编辑修复

## 行为与兼容

- 调整层确认时，将最终配置与进入面板时的快照比较；不能因实时预览已经写入相同值而跳过撤销记录。改回原值只恢复画面，不增加撤销步骤。
- 曲线和渐变的 HUD、旧面板、新建入口共用 LUT 编辑状态转换。打开后未编辑或把参数改回原值，直接使用原始 LUT，避免重新拟合或量化改变画面。
- 老作品仅保存合成 LUT，无法唯一恢复原来的主曲线与各通道控制点组合，也无法唯一恢复原始渐变色标。此时按实际 LUT 采样重建面板，编辑后使用重建的节点；未编辑时仍逐字节保留原配置。
- 图层类型来自引擎节点或显式属性，不从用户可编辑的名称推断。描边继续支持已保存的 `is_stroke` / `isStrokeLayer` 属性及真实图层样式。
- 新建填充层仍是预填色颜料层，用 `reverie_is_fill` 标记，复制时保留，`layers.xml` 以 `paintlayer is_fill="1"` 保存像素和标记。栅格化创建普通颜料节点，撤销恢复原节点。旧作品中只有名称、没有类型标记的伪填充层按普通颜料层打开，像素保留，可继续按普通颜料层编辑。

## LUT 中的编辑信息

渲染器继续只读取原有前缀：曲线为 768 字节 RGB 三通道，渐变为 1024 字节小端 ARGB。可选编辑信息紧跟前缀，整数和浮点数采用大端序：

- 公共头：4 字节 `RVL1`
- 曲线：依次保存主曲线、R、G、B；每组为一个 int32 节点数，随后为若干 `(float32 x, float32 y)`
- 渐变：int32 反向标志、int32 色标数，随后为若干 `(float32 position, int32 ARGB)`

解码校验版本、长度、数量和坐标范围；未知或损坏的编辑信息回退到前缀 LUT。整个字节数组仍沿用配置快照、`layers.xml` 的 Base64 和录制事件的十六进制编码，旧版引擎可继续渲染前缀。
