# 双指旋转实时锁定预览（issue #26）

## 行为

- 旋转意图仍要求至少 0.6° 净转角，往返小抖动不会累计激活吸附。
- 激活后，进入设置的捕获范围即精确锁定至最近的 90° 倍数，不需要松手。
- 锁定后使用捕获范围的 1.15 倍作为退出范围，减少边界抖动。默认捕获 5°，释放 5.75°。
- 进入吸附时允许向目标角度对齐；释放时只应用越过退出边界的角度，不将锁定期间的转角一次性补到画面。
- 释放后暂时禁止再次捕获同一目标，直到离开捕获范围或反向穿过目标，避免下一帧立即吸回。
- 中途静止超过 150ms 后的参考点更新不重建吸附状态。最终抬手不应把已释放的角度再次拉回。
- 触觉反馈依据实际锁定状态触发；平移和缩放仍按原逻辑运行，旋转中心补偿使用实际显示的角度增量。

## 影响范围

改动限定于 RotationSnapGesture、CanvasTouchView 的状态接入及测试。未改变原生引擎、撤销阈值、三指菜单或图形识别。
旧的连续磁性曲线工具函数保留，但旋转手势不再使用它映射角度。原有激活连续性测试改为实时精确锁定的契约测试；净转角防误触测试保留。

## 真机验收（待执行）

开启旋转和 5° 吸附，先画几条可辨认的笔画：

1. 从倾斜方向双指转向 0°、90°、180°、270°，不抬手，画面应立即精确对齐。
2. 保持手指接触，微小晃动和静止 1 秒，画面应保持标准角度；不应重复振动。
3. 继续转动超过退出范围，画面应从锁定角度继续旋转，不突然补跳约 5°；松手不再次拉回。
4. 释放后反向转回目标，能够重新吸附。顺时针、逆时针以及跨 0°/360° 均测试。
5. 吸附期间同时双指平移、缩放，手指中心对应的画面位置不应漂移。
6. 关闭吸附、关闭旋转或锁定视图，分别验证自由旋转/禁止旋转行为。
7. 静止纯缩放的小抖动不应触发吸附；旋转停顿不应误撤销；全新双指轻点撤销和三指菜单正常。
8. 阈值分别设为 1°、5°、30°，检查捕获范围符合设置。

单元测试覆盖纯角度状态机，不能替代上述触摸、触觉反馈和视觉验证。
