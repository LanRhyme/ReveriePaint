# SRT 独立帧格与安全删除

基线：v1.8.5，提交 2bc4260f0d3220fa28b043912aab9cb16d272cd1

## 问题与行为

普通新增颜料图层过去没有动画通道，因此时间轴没有帧块，画面会在其他字幕分镜共用。图层面板的删除会删除整条图层，而非当前帧格。

- 动画文档新增颜料图层时创建当前格的关键帧及结束边界
- SRT 文档以当前字幕分镜的起止位置为范围；无字幕处使用单帧范围
- 点击空白位置可在同一轴上创建独立帧格；已有连续画面会保留范围外的原内容
- 普通删除保留空白关键帧，阻止前一格画面延续进已删除的位置
- 字幕主轨的关键帧位置保留，清除画面不会重新编号字幕
- 长按左侧图层标题弹出整条图层删除确认；确认以图层 ID 和文档代际定位，防止索引漂移
- 时间轴底部新增横向滑条，只滚动视口，不移动播放头
- 不新增 JNI 接口或修改原生库；像素、关键帧和撤销仍由 Krita 持有

## 影响范围与回归审查

- 图层列表、快捷图层窗、快捷键调用的 addLayer/removeLayer
- 图片导入到新颜料图层、类型为颜料层的新增入口
- 时间轴单击、帧菜单、工具栏删除、批量删除及复制帧
- 笔画开始前的 SRT 帧隔离；普通非 SRT 文档保留手动作画偏好
- 时间轴空白帧显示、缩略图刷新、浮动与迷你布局
- 图层增删重排、撤销重做、旧 SRT 工程及 .revp 保存重开
- 背景/前景常驻层及组不能当作独立颜料帧清除；删除整轴必须确认

所有新增文档操作在 runCore 的渲染线程执行。UI 只读取镜像，不保存第二份像素数据。删除使用关键帧替换，避免直接清空共享像素。替换前先保存结束位置的原曝光；同一操作在一个原生撤销宏中执行。批量删除按格分别记录撤销。

## 验证

- AnimationCelPlanTest：相邻格隔离、局部清除、首格、长曝光、字幕边界、重复落笔不添加无效撤销
- SrtStoryboardTest：原有字幕解析与时间映射回归
- debug 验证入口：在全新 64×64 临时画布上逐像素检查 11/12 格、删除、撤销重做、字幕末格与保存重开
- 完整构建与模拟器验证结果在交付验证记录中列出；不得把纯模型测试视为原生引擎验证

测试安装包采用独立 applicationIdSuffix=.srtfix，版本基线仍为 1.8.5，不替换正式版应用数据。
