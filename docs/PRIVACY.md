# 崩溃报告与隐私说明

> 适用版本: 1.6.x 及以后 (含崩溃遥测的构建) · 最后更新 2026-10-30
> 技术细节见 [TELEMETRY.md](TELEMETRY.md)

## 一句话

官方构建会把**闪退现场**发给我们，用来修 bug。发出去的只有崩溃堆栈和设备信息，
**没有你的画、没有文件名、没有账号密码**。不喜欢可以关，关掉会连本地标识一起清掉。

## 我们收什么

| 字段 | 例子 | 为什么需要 |
|---|---|---|
| 崩溃堆栈 | `java.lang.NullPointerException at …` / `SIGSEGV` + 模块偏移帧 | 定位崩在哪一行代码 |
| 崩溃类型 | `java_crash` / `native_crash` / `anr` | 区分 Java 异常、引擎信号段错误、卡死无响应 |
| 设备信息 | OnePlus / PLQ110 / Android 16 (SDK 36) / 指纹 | 判断是不是某机型或某 ROM 的共性问题 |
| 内存 | 总内存 12288 MB | 低内存机型的内存压力归因 |
| 版本 | 1.6.1 (48) / arm64-v8a | 确认是哪个构建 |
| 页面与工具 | `PAINTING` / `brush` / 画布 2400×3200 / 12 个图层 | 判断崩在哪个功能、什么规模上 |
| 动作标签 | `Tool/switch`、`Brush/load_preset`、`History/undo` | 还原"崩之前用户在做什么"，**只有动作名，没有名字** |
| 最近 100 行日志 | 已脱敏的进程日志 | 崩溃前的引擎报错 |
| 随机安装标识 | 一组随机 UUID | 只用于"同一台设备一天最多 5 条"的限流与去重 |
| 发生时间 | Unix 时间戳 | 判断是不是某个版本引入的回归 |

## 我们绝不收集

- 画作内容：像素、缩略图、图层内容、选区、参考图
- 任何文件名：`.revp` 工程名、导出图名、笔刷预设名、图层名、画集名
- 任何路径：只保留"有一个文件"这个事实，名字替换成 `*.<扩展名>`
- 账号凭据：WebDAV 用户名密码、Token、Cookie、`Authorization` 头
- 设备标识：`ANDROID_ID`、IMEI、序列号、MAC、手机号、邮箱
- 位置信息（应用不申请任何定位权限）
- 剪贴板、输入法内容、已安装应用列表
- 广告或统计 SDK 的任何标识；本应用**没有**接入任何第三方统计/广告 SDK
- IP 地址：服务端不记录、不哈希、不落库

## 开关

- **默认开启**：崩溃现场是修 bug 的必需品。首次启动会在主页顶部显示一条一次性告知，不打断任何操作
- **关闭方式**：设置 → 隐私与诊断 → 崩溃报告自动上报
- **关闭后**：清空待上报队列、删除本地安装标识、不再发起任何上报请求
- **手动上报**：默认全自动,不需要你点任何按钮；只有你把自动上报关掉之后,崩溃弹窗才会出现「仅上报这一条」,用于一次性上报

## 数据去了哪里

上报发往维护者自建的 `https://telemetry.lanrhyme.top`(Cloudflare Worker + D1),接收端代码在
[`telemetry/worker/`](../telemetry/worker/) 完全开源。没有接入任何第三方统计或崩溃分析服务。

## 保留期

服务端数据库保留 **180 天**，由每日定时任务删除更早的数据（`telemetry/worker/src/index.js` 的 `scheduled`）。
本地崩溃日志保存在应用私有目录，超出 30 天不再上报，你可以随时通过崩溃弹窗导出或删除。

## 你的选择权

- 想知道某次崩溃到底发了什么：崩溃弹窗里可以预览、复制、导出完整日志（本地内容比上报内容更全，多出你的文件名与路径）
- 想完全离线：自行编译时不注入 `TELEMETRY_ENDPOINT`，或加 `-Ptelemetry=false`
- 想了解实现：上报端代码在 [`telemetry/worker/`](../telemetry/worker/) 完全开源，字段规约在 [TELEMETRY.md](TELEMETRY.md) §5
