# 真湿墨层 (Wet Overlay v2) 设计

日期: 2026-08-25 夜
状态: 已批准 (用户确认)
前序: docs/superpowers/specs/2026-08-25-wet-ink-preview-design.md 的架构升级。
v1 简化折线预览存在不可调和的外观失配(图像笔尖颗粒/软边/流量), 门控排除后
覆盖面塌缩且裸管线步进感暴露。v2 用真实 dab 像素做即时显示, 全笔刷像素级正确。

## 核心思路: 不重复画, 直接读

笔画照旧实时画进图层设备(语义零改动); 新增一条廉价显示旁路:

```
flushStrokeBatch 出 dab → 图层设备脏区
      ↓ renderWetOverlay: 设备脏区 → 色彩转换 → NEON 拷入覆写位图
      ↓ (跳过多图层投影合并, 只拷本笔新增区域)
CanvasTouchView 下帧把位图叠画在画布上方  ← dab 后 ~1 帧可见
      ↓ 正常渲染管线追上 (水位线机制判定真墨已上屏)
清除覆盖位图
```

## 语义安全分析

- 覆盖内容 = 本笔真实 dab 结果, 颗粒/软边/压感/流量/纹理全部正确
- 显示帧已含当前图层旧内容; 新像素叠加其上 ≈ normal 混合正确结果;
  图层不透明度乘入预览 alpha; 非正常混合模式短暂近似、正式渲染到达即校正
- 选区约束已在绘制侧由 painter->setSelection 保证, 覆盖无需二次裁剪
- 撤销/录制/事务/取消回滚全部走既有路径, 零改动
- 橡皮擦/涂抹不参与(挖除语义无法用叠加表达), 维持直绘无即时显示
- 空气笔刷纳入(真实 dab 无失配)

## 笔迹预测尾巴

MotionPredictor 保留: 预测点只画笔尖前方短 streak (上帧预测点→本帧预测点),
真墨 dab 到达自然覆盖。不再有长折线尾巴。

## 改动面

| 侧 | 内容 |
|---|---|
| C++ | m_wetDirtyAccum 脏区累计(BRUSH 非擦除的 flush/tap/kick 路径); `renderWetOverlay(Bitmap,outRect)` 复用既有色彩转换+NEON 拷贝; `clearWetOverlay()` |
| Kotlin VM | 湿墨位图生命周期(预分配 doc 尺寸, 复用); 排水 runnable/kick/touchEnd 三处取数; 上屏后清除 |
| Controller | 重写为覆盖位图合成器(doc 变换同现路径); 折线路径删除; 预测 streak 保留 |
| 清理 | 折线专用代码退役; brushTipKind 若无引用则连 JNI 一起移除 |

门控简化: BRUSH 工具即可用(选区约束天然生效); 原 tipKind/纸纹等排除逻辑作废;
「落笔即时预览」「笔迹预测」两开关语义不变。

## 已知取舍

- 非正常混合模式图层上作画时湿墨瞬间以 normal 叠加(≤2 帧校正)
- 覆盖位图为文档尺寸单份(~8MB @1080×1920), 预分配复用

## 测试策略

JUnit: 水位线清除状态机(纯逻辑部分)。真机: 全笔刷类抽样(形状/颗粒/软边/
低流量/空气笔刷)逐一看即时性与替换无缝性; 橡皮/涂抹行为不变; 录制回放不受污染。
