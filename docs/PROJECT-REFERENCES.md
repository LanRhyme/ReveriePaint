# 按作品保存参考图（#78）

## 问题与范围

主线 `659d1d1e` 将参考图保存在应用级 `ref_images/` 和 `paint_prefs` 中，新建、切换作品时不会切换这份数据，因此 A 作品的参考图会出现在 B 中。#78 中的长按取色、点击添加图片入口已经存在，本次补齐参考图的作品归属与 `.revp` 携带能力。

影响范围包括参考图导入与选图、窗口状态、新建/打开/离开作品、手动保存、自动保存和导出。绘画像素、图层、录制事件、JNI 签名、原生库均不修改。

## 存储与线程

- 复用原生 `storeRevAsset` / `revAssetBytes`，参考图作为文档资源由已有 `.revp` 保存路径写入 `assets/`，不依赖相册 URI 或设备路径。
- `reverie-reference-images-v1.zip` 按顺序存储 `0.png`、`1.png` 等图片。PNG 已压缩，内层 ZIP 使用 STORED，避免再次压缩。
- `reverie-reference-state-v1.bin` 保存版本标识及窗口打开、灰度、翻转、页签、折叠、缩放、旋转和平移状态。窗口位置、尺寸和允许旋转设置仍是设备偏好。
- 图片解码和编码在 IO 线程；资源读取/写入通过渲染线程排队；Compose 只持有用于参考窗口显示的状态镜像。没有复制绘画画布像素。
- 原生资源接口忽略空字节，清空图片必须写入有效的空 ZIP。原生新建/关闭、非 `.revp` 打开路径不会自动清空资源表，因此这些入口显式重置本功能的两个资源键，不修改其他资源。
- 每个文档会话和导入操作都有独立编号，离开、清空或切换作品后，过期的异步解码和已排队导入不能回写新作品。
- 保存或导出遇到尚未结束的导入会等它完成；自动保存跳过正在导入的时刻，后续周期再保存。导入失败保持原参考图。
- 选图界面的已选项使用仅在内存有效的身份标识，并直接复用当前参考位图。重新打开作品后仍可保留、删除和追加参考图，无需重新访问原相册文件。这些标识不进入作品文件。

## 兼容与限制

- 没有上述资源的旧作品按“无参考图”打开，避免把全局参考图误归属给任意作品。
- 旧 `ref_images/` 文件保留不删除，在参考窗口设置中提供“导入旧版参考图”，由用户决定添加到哪个作品。
- 参考图最多 50 张。单次读取源文件、ZIP 中 PNG 总量、解码位图总量分别设有 64 MiB 上限；图片按采样尺寸解码，最长边目标约 2048 像素。它是绘画参考副本，不是原图归档。
- 分享 `.revp` 会包含参考图；PNG/JPEG 等扁平图像导出不携带参考图。作品体积和保存开销会随参考图增加。
- 损坏图片资源显示恢复失败提示，不把不完整导入替换为现有参考图。未知或无效的状态数据回退到默认显示状态。
- 本次没有新增参考图撤销栈，也不改变绘画撤销/重做的含义。

人工验收建议：

1. 新建 A，参考窗口添加图片，调整缩放/翻转并保存。
2. 新建 B，确认没有 A 的参考图；添加另一张图并保存。往返打开 A/B，确认图片和显示状态独立。
3. 在 A 的选图界面保留已有图片、追加一张，再删除其中一张；保存并重开，确认结果不变。
4. 清空 A 的参考图并保存，确认 B 不受影响；结束应用进程后重开确认。
5. 导出 A 的 `.revp` 并在其他设备导入，确认参考图可见，不要求原相册存在。当前自动测试覆盖副本与进程重启，跨设备实测应单独记录。
6. 如果有旧版参考图，在窗口设置中显式导入到目标作品，确认其他作品不会自动获得它们。
7. 检查原有点击“添加图片”和长按取色仍可用。
