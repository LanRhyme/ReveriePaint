# 动画轨道模型与音频条

基线 v1.8.5 (分支 `fix/srt-independent-cels`)

## 轨道

时间轴以**轨道**为单位显示 (根图层组), 一条轨道里可以有多个图层:

- 每个帧格是该轨道的一次独立画格: 组内每个可动画颜料层在同一帧建立自己的关键帧
- 帧格缩略图按子层从底到顶叠加, 使用各层不透明度, 显示这一格的合成效果
- 在轨道里新增图层只增加这一格的内容, 不会新增轨道行
- 只有"添加轨道"才创建新的根组, 命名 `轨道 N` / `Track N`
- 图层面板仍显示真实图层结构 (轨道组 + 组内图层)

引擎限制: `layerAnimatable()` 明确排除组 (`ReverieCoreAnimation.cpp:585`), 组本身没有关键帧
通道。因此"同一格"是 Kotlin 侧对组内多个子层关键帧的同步操作, 像素与撤销仍由 Krita 持有,
不改 C++、不改预编译库。

### 旧工程迁移

旧动画工程没有根组, 直接按图层显示会变成"每个图层一条轨道"。载入动画工程时
(`ensureSingleAnimationTrackOnRenderThread`):

- 没有根组: 新建 `轨道 1`, 把所有顶层散层批量移入, 并为每个子层开启动画
- 已有根组: 把仍然露在外面的顶层散层并入第一条轨道, 不再新建
- 静态绘画工程不触发 (只在 `animationEnabled()` 为 true 的工程执行)

## 音频

音频仍是 `.revp` 的原始资源, 位置信息单独存在 `reverie.anim.audio_clips`
(`name<TAB>startFrame<TAB>durationFrames`), 前缀与动画标记一致, 不会被识别成音频资源。

- 导入音频时读取时长并换算成帧数, 默认起点为当前帧
- 时间轴上方每条音频一行, 左右拖动修改起始帧, 松手后写入工程
- 长按音频条二次确认后移除: 停止播放、清空资源与临时文件、更新位置元数据
- 播放时按各自起始帧启动, 已经过的位置用 `seekTo` 对齐, 循环播放沿用原有开关
- 旧工程只有音频字节时, 位置按第 0 帧、时长按 4 秒兜底, 拖动后会写回工程
